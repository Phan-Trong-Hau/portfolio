Bida 8 Bi

Personal project · vibe coded

2026

I just wanted to play 8-ball pool with my friends. The pool apps on the market were laggy, buggy, full of ads, and didn’t let us play together easily, so I vibe coded my own to fix my own pain point.

  • 3D table rendered with Three.js, mobile-first touch controls for aiming, power, and cue spin.
  • Custom billiards physics with sub-stepped simulation, ball/cushion collisions, and top/back/side spin.
  • Real-time 2-player rooms over MQTT on WebSockets with 4-digit room codes; game state persists so a page reload resumes the match.
  • Bot opponent with 3 difficulty levels using ghost-ball aiming, cut angles, and clear-path checks.
  • Installable PWA with a service worker for offline play; real CC0 sound recordings embedded as base64 in a single HTML file.

JavaScript · Three.js · MQTT · WebSockets · PWA · Service Worker · GitHub Pages
