Mysheo runs online English classes. Study is where students, teachers, and staff manage everything around those classes.

Besides building core features, I assigned tasks in the team, reviewed code, merged branches for each release and handled production deployments. I also helped other developers work through hard code problems, at a time when AI was not much help with coding yet.

What it does

Learning platform

Students sign up for classes, take attendance and do assignments; teachers see their schedule and create classes; the admin team manages classes, lessons, licenses and users.

AI grading

The OpenAI API scores students’ answers to exercises and writes feedback, so students hear back right away instead of waiting for a teacher.

Instant notifications

WebSocket pushes class updates to students and teachers the moment something changes.

Google Sheets sync

Data syncs to Google Sheets in real time, so the operations team works in the spreadsheets they know, always with the latest numbers.

Roles

Role-based administration for students, teachers, and staff.

Media

Images and documents stored on Cloudflare.

How it works

  • FrontendReact/Next.js in TypeScript with Material UI.
  • BackendExpress.js with MariaDB and Redis.
  • QualityCypress end-to-end tests and Jest unit tests; Docker for deployments.
