About

Filum CX is Filum AI’s main product. Businesses use it to talk to customers on every channel from one inbox, with AI agents handling the repetitive work.

I worked on it with a 15-person engineering team, mostly on channel integrations, the reliability of the integration layer, frontend performance, and the automation system.

What it does

10+ channels in one inbox

Integrated Messenger, Zalo OA, 3CX and other channels into a central conversation manager supporting 80+ integrations.

Self-service troubleshooting

Centralized logging, alerting, credential monitoring, and retries across 80+ integrations and 300+ Cloud Functions, rolled out in about a month.

Automation workflows

Helped build the automation system with 10+ triggers and 10+ actions.

Faster frontend

Lazy loading, tree shaking, list virtualization, and render optimization to cut wasted resources.

How it works

  • FrontendNext.js with Ant Design, shadcn/ui, and TanStack Query/Table.
  • IntegrationsNode.js and Python services on GCP Cloud Functions and Cloud Run.
  • CostCut monthly logging costs by 60%, from $500 to $200, by removing redundant logs and tuning Cloud Run resources.
  • SecurityAI-assisted security audits, including finding GCP access tokens exposed through custom tool APIs.
