Congress delegate photo frame

A photo-frame tool for the Congress of the Ho Chi Minh Communist Youth Union of Đắk Lắk province (term 2025–2030).

  • Next.js
  • React
  • TypeScript
  • Tailwind CSS
  • react-easy-crop
  • html-to-image
  • AWS S3

Freelance project. The source code is private.

About

Before the congress, every delegate was invited to share a short message. Making each card by hand in a design tool would not scale.

This tool lets each delegate make their own card in under a minute, with the official frame, and download it to post or send.

What it does

Photo upload & crop

Upload a portrait and crop it to fit the frame’s circle.

Name, title, message

Fill in the delegate’s name, position, and a message of up to 500 characters.

Live preview

The finished card updates as you type, exactly as it will be exported.

One-click download

Export the card as a PNG named after the delegate.

How it works

  • Croppingreact-easy-crop for the crop step, then a canvas helper to cut the final image.
  • Exporthtml-to-image renders the live preview into a high-resolution PNG.
  • UploadsA Next.js API route signs an S3 upload URL, so photos go straight from the browser to AWS S3.
