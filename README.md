# Phan Trong Hau — Portfolio

Responsive personal portfolio based on Phan Trong Hau's supplied CV. Plain HTML, CSS, and JavaScript; no build step or package dependencies.

## Run locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. Deploy this directory to any static host when ready.

## Edit

- `index.html`: biography, career history, project contributions, contact links.
- `styles.css`: responsive layout and visual theme.
- `assets/Phan_Trong_Hau_CV.pdf`: downloadable CV.
- `script.js`: current footer year.

Project visuals are conceptual diagrams, not product screenshots. Contributions and metrics are attributed to the relevant employment/team context. External product links may require authentication. LinkedIn is omitted because the CV does not provide an unambiguous profile URL. Google Fonts is optional; system fonts provide fallbacks.

This repository contains personal contact details and the source CV. Repository visibility is private. No website hosting is configured.
